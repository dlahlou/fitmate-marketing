# ASO (App Store et Google Play)

- `fiches/fr-FR.json`, `fiches/en.json` : source de vérité des textes (limites vérifiées par le script).
- `journal.md` : historique des changements, volumes de mots-clés, plan de mesure.
- `python -m scripts.aso_listings` : écart entre les fiches en ligne et les fichiers (lecture seule).
- `--apply play | ios | ios-promo` : application, **uniquement avec l'accord explicite de Driss**.
