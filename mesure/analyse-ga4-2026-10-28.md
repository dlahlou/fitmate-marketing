  « organisateur » ou de tests. GA4 ne distingue pas ici l'inscription en liste d'attente.

## 6. Trous de mesure

1. **Trafic interne non filtré** (hypothèse forte, à vérifier) : aucun filtre « trafic interne » constaté ; le pic du
   25-27/10 coïncide avec beaucoup de travail sur le site. → GA4 → Admin → Flux de données → Configurer les paramètres
   du tag → Définir le trafic interne, puis activer le filtre.
2. **Événements clés trop récents** : 0 avant le 25/10. Il faut 3 à 4 semaines de données propres avant de comparer.
3. **Pas d'événement dédié à la liste d'attente** : impossible de compter dans GA4 les inscriptions en liste d'attente
   par sport et secteur. → émettre `join_waitlist` (avec `sport`, `zone`) et le marquer comme événement clé.
4. **`(not set)` en page de destination** : 8 sessions sur 168 (5 %). Habituel pour des sessions sans `page_view`
   (onglets restaurés, événements isolés), à surveiller.
5. **Unassigned** : 4 sessions mais 2 événements clés, probablement les clics `/app` → store envoyés sans session.
6. **Spam / URL parasites** : en 28 j, une page de destination `/cs/news/xxx-…-c2lmz8.html` dans GA4 et une impression
   Search Console pour `/tom/mad/video-xxx-…html`. Hypothèse : le site renvoie une page (code 200) pour des adresses
   qui n'existent pas, que des robots de spam utilisent. → vérifier qu'une adresse inconnue renvoie bien un 404.
   Également `/data-deletion.html.` (point final) : lien mal copié quelque part.
7. **Pas de répartition pays / appareils / utm dans l'export quotidien** : c'est ce qui a bloqué les questions 3 à 5.
8. **Search Console** : 5 jours d'historique seulement (données depuis le 22/10).

## Réponses aux questions

1. **D'où viennent les visiteurs ?** Google (45 %), Direct (33 %), réseaux sociaux (12 %). Seul Google convertit de
   façon répétée (7 sur 12), sur un volume trop faible pour conclure fermement.
2. **Pages** : l'accueil (58 % des entrées) ; ensuite `/applications-sport-a-plusieurs`, quelques guides rando.
   Conversions : accueil (4), `/reseau-social-sportif` (2), `/run-clubs-paris`, `/organiser`, `/randonnee/chamonix`,
   `/sport/course-a-pied/hauts-de-seine` (1 chacune).
3. **Île-de-France / France / étranger** : non mesuré ici (accès API manquant).
4. **Mobile / ordinateur** : non mesuré ici (accès API manquant).
5. **Instagram / Facebook** : +17 sessions sociales sur 28 j, 0 conversion ; détail par utm non disponible.
6. **Trous** : trafic interne, événements clés récents, pas d'événement liste d'attente, Unassigned, URL parasites,
   export sans pays/appareils/utm.
